\begin{frame}{Conclusion}
  \begin{itemize}
    \item<1-> The base CNN is a useful general classifier but has a clear class-specific weakness.
    \item<2-> Stroma false negatives concentrate in a small number of competing classes.

    \item<4-> Binary expert classifiers substantially improve recall-oriented cancer metrics.
