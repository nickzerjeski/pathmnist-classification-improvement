\begin{frame}{Motivation}
  \begin{itemize}
    \item Histopathological analysis is central for cancer diagnosis.
    \item Manual image analysis is time-consuming and depends on expert judgement.
    \item In medical classification, false negatives for cancer-related tissue are especially costly.
    \item The goal is therefore recall-oriented improvement, not only higher accuracy.
  \end{itemize}
  \begin{block}{Project Question}
    How can we predict cancer tissue more reliably?
  \end{block}
\end{frame}
