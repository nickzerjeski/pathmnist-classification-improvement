\begin{abstract}
This work investigates whether an expert-based correction system can improve
cancer-related tissue classification on the PathMNIST dataset. As a reference
point, the official ResNet-50 benchmark is used, while a custom small CNN is
trained as the base model on the $224 \times 224$ image version. The base model
achieves strong performance for colorectal adenocarcinoma epithelium, but shows
weak performance for cancer-associated stroma. Analysis of the confusion matrix
and confidence distributions shows that many stroma samples are repeatedly
misclassified as debris, smooth muscle, or epithelium. To address this issue,
specialized binary expert classifiers are introduced for these confusion pairs
and applied only when the base model prediction has insufficient confidence. The
resulting cancer expert system substantially improves stroma recall and stroma
$F_2$ score, while also improving the overall cancer-vs.-rest performance. These
results show that targeted expert classifiers can correct specific weaknesses of
a base model and improve recall-oriented cancer detection metrics. Although the
system is only a simplified example, it demonstrates the potential of
expert-based correction strategies for medical image classification.
\end{abstract}
